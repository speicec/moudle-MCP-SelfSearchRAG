# Spec: 全链路可视化系统 (Pipeline Visualization)

## 概述

实现文档从上传到检索的全链路可视化，让用户直观理解 RAG 系统的处理流程。包含四个核心模块：

- **处理时间轴**：展示 Pipeline 各阶段的时间消耗和关键指标
- **分块浏览器**：实时展示 Chunk 的层级结构和内容
- **检索过程动画**：可视化相似度搜索和 Parent 扩展过程
- **统计仪表盘**：全局性能数据和趋势分析

## 设计原则

### 用户体验

1. **简洁易懂**：面向最终用户，避免技术术语堆砌
2. **实时反馈**：处理过程中实时更新，让用户感知进度
3. **交互探索**：支持点击、展开、筛选等交互操作
4. **性能平衡**：动画流畅但不占用过多资源

### 视觉风格

- 使用中文标签和提示
- 颜色编码：绿色表示成功/高质量，黄色表示中等，红色表示问题/低质量
- 卡片式布局，清晰分层
- 渐变动画而非瞬间切换

## 一、处理时间轴 (PipelineTimeline)

### 1.1 数据结构

```typescript
interface PipelineTimelineEvent {
  type: 'pipeline:start' | 'stage:start' | 'stage:metrics' | 'stage:complete' | 'pipeline:complete';
  documentId: string;
  stage?: 'ingest' | 'parse' | 'embed' | 'index';
  timestamp: number;
  metrics?: StageMetrics;
}

interface StageMetrics {
  durationMs: number;
  // Ingest 阶段
  fileSizeBytes?: number;
  // Parse 阶段
  pagesExtracted?: number;
  tokensExtracted?: number;
  tablesDetected?: number;
  formulasDetected?: number;
  // Embed 阶段
  embeddingDimension?: number;
  chunksEmbedded?: number;
  // Index 阶段
  smallChunksCreated?: number;
  parentChunksCreated?: number;
}

interface TimelineState {
  documentId: string | null;
  startTime: number;
  stages: StageProgress[];
  totalDurationMs: number;
  status: 'idle' | 'running' | 'completed' | 'error';
}

interface StageProgress {
  name: string;
  label: string; // 中文标签：读取、解析、向量化、索引
  status: 'pending' | 'running' | 'completed' | 'error';
  startTime: number;
  endTime: number;
  durationMs: number;
  metrics: StageMetrics | null;
}
```

interface RetrievalFlowState {
  query: string;

interface RetrievalStep {
  name: 'query-embedding' | 'similarity-search' | 'parent-expansion';
  label: string; // 中文：生成向量、相似度搜索、扩展上下文
  status: 'pending' | 'running' | 'completed';
  durationMs: number;
  output?: {
    embedding?: number[];
    matches?: SimilarityMatch[];
    expandedChunks?: ExpandedChunk[];

}

interface SimilarityMatch {
  smallChunkId: string;
  similarityScore: number;
  rank: number;
}

interface ExpandedChunk {
  smallChunkId: string;
  parentChunkId: string;
  parentContentPreview: string;
  similarityScore: number;
}

interface RetrievalMatchEvent {
  type: 'retrieval:match';
  query: string;
  match: SimilarityMatch;
  timestamp: number;
}
