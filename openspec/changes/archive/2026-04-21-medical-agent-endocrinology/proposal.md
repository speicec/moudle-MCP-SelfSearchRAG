# Medical Agent: Endocrinology Domain

## Problem

用户上传内分泌领域医学文献后，缺乏专业的医学知识检索能力：

1. **实体识别缺失**：无法识别药物、疾病、指标的别名和关系
2. **术语扩展不足**：检索时只用原词，错过大量同义表达
3. **证据等级未评估**：无法区分指南级别和文献质量
4. **回答缺乏结构**：无来源引用、置信度标注、医学提醒

**用户痛点示例**：
```
用户: "糖尿病患者合并肾功能不全，二甲双胍是否还能用？"

当前系统: 返回模糊的检索片段，无临床决策支持

期望系统:
## 结论
二甲双胍在肾功能不全患者中使用需谨慎，具体取决于eGFR水平。

## 详细说明
根据ADA 2024指南：
• eGFR ≥45: 可正常使用
• eGFR 30-45: 慎用，需减量
• eGFR <30: 禁用

## 证据等级
Grade B - ADA指南推荐

## 来源引用
1. ADA Standards 2024, Section 9

## 注意事项
请遵医嘱，本回答仅供参考
```

## Proposed Solution

构建内分泌领域医学知识检索 Agent：

1. **医学词典层**：预置内分泌领域核心词典
   - 疾病：糖尿病、高血压、甲状腺疾病
   - 药物：降糖药、降压药、甲状腺药物
   - 指标：HbA1c、eGFR、血压、血脂
   - 关系：禁忌、慎用、相互作用

2. **实体识别层**：从用户查询中提取医学实体
   - 词典匹配 + 别名展开
   - 实体标准化（统一名称）

3. **智能检索层**：基于实体构建检索策略
   - 术语扩展（别名、关联词）
   - 领域过滤（年份、指南来源）
   - 多路检索融合

4. **证据评估层**：评估检索结果质量
   - 文献类型识别（RCT、Meta、指南）
   - GRADE等级映射
   - 时效性判断

5. **结构回答层**：医学专业格式输出
   - 结论 + 详细说明
   - 证据等级 + 来源引用
   - 不确定性标注 + 医嘱提醒

## Scope

| 组件 | 改动 |
|------|------|
| 新增 `src/medical/` | 医学模块完整目录 |

| 实体识别器 | 词典匹配 + 标准化 |
| 查询规划器 | 策略构建 + 术语扩展 |
| MCP Tool | `medical_query` 新工具 |
| 回答模板 | 医学结构化输出 |

## Success Criteria

- [ ] 内分泌领域词典覆盖率 >80% 常见实体
- [ ] 实体识别准确率 >90%（词典匹配）
- [ ] 术语扩展提升召回率 >30%
- [ ] 回答格式符合医学规范
- [ ] MCP Tool 可被 Claude Desktop 调用

## Risks

| 风险 | 级别 | 缓解措施 |
|------|------|----------|
| 词典维护成本 | 低 | 静态数据，按指南更新 |
| 识别准确度 | 中 | 多层匹配（别名+上下文） |
| 回答过于绝对 | 高 | 强制不确定性标注 |
| 领域扩展性 | 低 | 模块化设计，支持后续扩展 |
