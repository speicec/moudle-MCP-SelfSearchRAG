```

│  │                                                                                     │   │

│                                                                                              │

## 断崖检测算法流程

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│                        断崖检测算法 (Cliff Detection Algorithm)                              │
└─────────────────────────────────────────────────────────────────────────────────────────────┘

  输入: Embedding序列 [e1, e2, e3, ..., en]
        (每个embedding代表一个句子的语义向量)

  Step 1: 计算相邻相似度
  ────────────────────────────────────────────────────────────────────────────────────────────

    ┌───────────────────────────────────────────────────────────────────────────────────────┐
    │                                                                                       │
    │   sim_1 = cosine(e1, e2)                                                              │
    │   sim_2 = cosine(e2, e3)                                                              │
    │   sim_3 = cosine(e3, e4)                                                              │
    │   ...                                                                                 │
    │   sim_{n-1} = cosine(e_{n-1}, en)                                                     │
    │                                                                                       │
    │   输出: 相似度序列 [sim_1, sim_2, ..., sim_{n-1}]                                     │
    │                                                                                       │
    │   例如: [0.85, 0.82, 0.78, 0.45, 0.72, 0.68, ...]                                     │
    │                       ↑                                                               │
    │                       │                                                               │
    │                       断崖！sim突然从0.78降到0.45                                     │
    │                                                                                       │
    └───────────────────────────────────────────────────────────────────────────────────────┘

  Step 2: 找候选断崖点
  ────────────────────────────────────────────────────────────────────────────────────────────

    candidates = {i | sim_i < similarityThreshold (0.7)}

    例如: candidates = [3, 6, 9]  // sim_3=0.45, sim_6=0.55, sim_9=0.42

  Step 3: 验证梯度
  ────────────────────────────────────────────────────────────────────────────────────────────

    ┌───────────────────────────────────────────────────────────────────────────────────────┐
    │                                                                                       │
    │   gradient_i = |sim_i - sim_{i-1}|                                                    │
    │                                                                                       │
    │   要求: gradient_i > gradientThreshold (0.15)                                         │
    │                                                                                       │
    │   例如:                                                                               │
    │   gradient_3 = |0.45 - 0.78| = 0.33 > 0.15 ✓                                          │
    │   gradient_6 = |0.55 - 0.68| = 0.13 < 0.15 ✗ (排除)                                   │
    │   gradient_9 = |0.42 - 0.55| = 0.13 < 0.15 ✗ (排除)                                   │
    │                                                                                       │
    │   validated = [3]                                                                     │
    │                                                                                       │
    └───────────────────────────────────────────────────────────────────────────────────────┘

  Step 4: 滤噪
  ────────────────────────────────────────────────────────────────────────────────────────────

    要求: minCliffWidth (2) 个相邻候选点

    例如: validated = [3] 只有1个点
          如果有 [3, 4] 连续2个点，则保留

  Step 5: 选最终边界
  ────────────────────────────────────────────────────────────────────────────────────────────

    相邻断崖取梯度最大者

  输出: 语义边界位置 [3]
        表示: 在第3句和第4句之间切分
```

## Small-to-Big检索流程

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│                        Small-to-Big检索流程 (Retrieval Process)                             │
└─────────────────────────────────────────────────────────────────────────────────────────────┘

  用户查询: "哪个季度销售额最高？"

  ┌──────────────────────────────────────────────────────────────────────────────────────────┐
  │  Phase 1: 小块精准定位                                                                   │
  ├──────────────────────────────────────────────────────────────────────────────────────────┤
  │                                                                                           │
  │  Step 1.1: 查询向量化                                                                     │
  │  ────────────────────────────────────────────────────────────────────────────────────── │
  │                                                                                           │
  │    queryEmbedding = embed("哪个季度销售额最高？")                                          │
  │    → [0.12, 0.34, -0.56, ..., 0.23]  (384维向量)                                          │
  │                                                                                           │
  │  Step 1.2: 向量检索                                                                       │
  │  ────────────────────────────────────────────────────────────────────────────────────── │
  │                                                                                           │
  │    遍历所有 Child Chunks:                                                                 │
  │                                                                                           │
  │    Child #1: cosine(query, child1) = 0.42                                                │
  │    Child #2: cosine(query, child2) = 0.58                                                │
  │    Child #3: cosine(query, child3) = 0.85 ✓ ← 高相似度                                   │
  │    Child #4: cosine(query, child4) = 0.31                                                │
  │    ...                                                                                    │
  │                                                                                           │
  │  Step 1.3: 阈值过滤                                                                       │
  │  ────────────────────────────────────────────────────────────────────────────────────── │
  │                                                                                           │
  │    filtered = filter(results, similarity > 0.75)                                         │
  │    → [Child #3 (score=0.85)]                                                             │
  │                                                                                           │
  └──────────────────────────────────────────────────────────────────────────────────────────┘
                    │
                    │ 匹配到 Child #3
                    │
                    ▼
  ┌──────────────────────────────────────────────────────────────────────────────────────────┐
  │  Phase 2: 父块完整展开                                                                   │
  ├──────────────────────────────────────────────────────────────────────────────────────────┤
  │                                                                                           │
  │  Step 2.1: 获取父块                                                                       │
  │  ────────────────────────────────────────────────────────────────────────────────────── │
  │                                                                                           │
  │    parent = getParentChunk(Child #3)                                                     │
  │    → Parent Chunk A                                                                      │
  │                                                                                           │
  │    Parent Chunk A 内容:                                                                   │
  │    "2023-2024年销售分析报告                                                               │
  │     第一季度销售额120万元，环比增长15%                                                     │
  │     第二季度销售额150万元，环比增长25%                                                     │
  │     第三季度销售额180万元，环比增长20%                                                     │
  │     第四季度销售额210万元，环比增长16.7%，全年最高                                        │
  │     全年累计销售额660万元，较去年增长75%..."                                              │
  │                                                                                           │
  │  Step 2.2: 提取上下文窗口                                                                 │
  │  ────────────────────────────────────────────────────────────────────────────────────── │
  │                                                                                           │
  │    在 Parent 中定位 Child #3 的位置                                                       │
  │    Child #3 内容: "第四季度销售额210万元，环比增长16.7%"                                   │
  │    位置: 第180-220字符                                                                    │
  │                                                                                           │
  │    提取窗口: 前300字符 + 匹配内容 + 后500字符                                              │
  │    → "第三季度销售额180万元...第四季度销售额210万元，全年最高...全年累计销售额660万元"    │
  │                                                                                           │
  │  Step 2.3: 去重                                                                           │
  │  ────────────────────────────────────────────────────────────────────────────────────── │
  │                                                                                           │
  │    如果多个 Child 匹配到同一个 Parent，只返回一次                                          │
  │                                                                                           │
  └──────────────────────────────────────────────────────────────────────────────────────────┘
                    │
                    │ 返回 Parent Chunk A (或上下文窗口)
                    │
                    ▼
  ┌──────────────────────────────────────────────────────────────────────────────────────────┐
  │  最终返回给用户/LLM                                                                       │
  ├──────────────────────────────────────────────────────────────────────────────────────────┤
  │                                                                                           │
  │  {                                                                                        │
  │    smallChunkId: "child-3",                                                               │
  │    parentChunkId: "parent-A",                                                             │
  │    parentChunkContent: "2023-2024年销售分析报告...",                                      │
  │    contextWindow: "第三季度...第四季度销售额210万元，全年最高...",                         │
  │    similarityScore: 0.85,                                                                 │
  │    sourceDocumentId: "doc-sales-report",                                                  │
  │    windowStart: 150,                                                                      │
  │    windowEnd: 400                                                                         │
  │  }                                                                                        │
  │                                                                                           │
  └──────────────────────────────────────────────────────────────────────────────────────────┘
